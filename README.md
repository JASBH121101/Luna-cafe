# Luna Café ☕

**A Responsive, Bilingual Coffee Shop Website**

Luna Café is a modern coffee shop website concept built to demonstrate front-end web development skills. It combines a clean visual design with interactive features, responsive layouts, and a bilingual user experience.

Luna Café es un concepto de página web para una cafetería, desarrollado como proyecto de portafolio para demostrar habilidades de desarrollo web frontend. Combina un diseño moderno con funciones interactivas, adaptación a diferentes pantallas y una experiencia bilingüe.

## ✨ Features / Características

- **Responsive design:** Adapted for desktop, tablet, and mobile screens.
- **Bilingual interface:** Switch between English and Spanish.
- **Light and dark themes:** Choose the appearance that suits your preference.
- **Product menu:** Explore coffee drinks and other café products.
- **Interactive shopping cart:** Add products and review your selection.
- **Demo checkout:** Explore the purchase interface without processing real payments.
- **User-friendly navigation:** Navigate the website and quickly return to the top of the page.

- **Diseño adaptable:** Compatible con computadoras, tabletas y móviles.
- **Interfaz bilingüe:** Disponible en inglés y español.
- **Tema claro y oscuro:** Permite cambiar la apariencia visual.
- **Menú de productos:** Presenta bebidas y productos de cafetería.
- **Carrito interactivo:** Permite agregar productos y revisar la selección.
- **Compra de demostración:** Muestra la interfaz de compra sin procesar pagos reales.
- **Navegación sencilla:** Facilita el recorrido por las distintas secciones.

## 🛠️ Technologies / Tecnologías

- HTML5
- CSS3
- JavaScript

The project uses standard frontend technologies to build the user interface and interactive elements.

El proyecto utiliza tecnologías frontend estándar para construir la interfaz y sus elementos interactivos.

## 🎯 Project Purpose / Propósito

Luna Café was created as a portfolio project to showcase web design, responsive development, and frontend interaction skills. It serves as a conceptual example of how a small business could present its products online.

Luna Café fue creado como proyecto de portafolio para demostrar habilidades de diseño web, desarrollo adaptable e interactividad frontend. Es un ejemplo conceptual de cómo un pequeño negocio podría presentar sus productos en línea.

**Note:** This is a demonstration project, not a live commercial storefront. The checkout interface does not process real payments.

**Nota:** Este es un proyecto demostrativo, no una tienda comercial en funcionamiento. La interfaz de compra no procesa pagos reales.

1. Clone or download this repository.

1. Cloná o descargá este repositorio.
